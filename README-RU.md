# typer

Windows-скрипт на Python для посимвольного ввода текста из `Text.txt` в активное окно.

Как я уже сказал, скрипт печатает тексты. Для начала печати необходимо поставить курсор в нужное место и запустить скрипт.

## Требования

* Windows 10 / 11
* Python 3.10+

##Python 3.12 вы можете скачать из Microsoft Store.
 
 После установки проверить его наличие:

```bash
python --version
```

Если команда выводит версию Python, установка завершена.

Дополнительные библиотеки не требуются.

## Подготовка

Поместить текст для печати в файл:

```text
Text.txt
```

**ВАЖНО: файл `Text.txt` должен быть сохранён в кодировке `UTF-8`.**

Использование другой кодировки может привести к некорректному отображению русских и других Unicode-символов.

## Запуск

1. Открыть Google Docs или другое приложение, в которое необходимо ввести текст.
2. Установить курсор в нужное место.
3. Запустить скрипт:

```bash
python main.py
```

4. В течение `START_DELAY` секунд переключиться в нужное окно.
5. Скрипт начнёт вводить содержимое `Text.txt`.

## Настройка

Основные параметры находятся в начале `main.py`.

| Переменная              | Назначение                                     |
| ----------------------- | ---------------------------------------------- |
| `TEXT_FILE`             | Имя текстового файла                           |
| `START_DELAY`           | Задержка перед началом ввода                   |
| `DELAY_MIN`             | Минимальная задержка между обычными символами  |
| `DELAY_MAX`             | Максимальная задержка между обычными символами |
| `PUNCTUATION_DELAY_MIN` | Минимальная задержка после пунктуации          |
| `PUNCTUATION_DELAY_MAX` | Максимальная задержка после пунктуации         |
| `ENTER_DELAY_MIN`       | Минимальная задержка после переноса строки     |
| `ENTER_DELAY_MAX`       | Максимальная задержка после переноса строки    |

## Ограничения

* Работает только на Windows.
* Целевое окно должно оставаться активным во время ввода.
* Целевое приложение должно принимать клавиатурный ввод.
* Скрипт не управляет Google Docs автоматически.

## Зависимости

Используются только стандартные модули Python:

```text
ctypes
pathlib
random
time
```

Сторонние пакеты не требуются.
